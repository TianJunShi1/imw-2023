# imw-2023

这是一个以 **HTML / CSS / JavaScript 前端基础训练** 为主的课程型作品仓库，内容以练习（`E*`）+ 项目（`P*`）组织，适合新同学从静态页面到交互脚本逐步上手。

## 1) 代码库整体结构（给新人的第一张地图）

### 根目录主入口
- `index.html` + `style.css` + `index.js`：综合展示页，包含多个视觉分区和交互逻辑（例如键盘输入小游戏、Canvas 刮刮乐区域等），也是快速感知仓库风格的最佳入口。
- `otherPage*.html`、`end.html`、`detail.html`：独立页面样例，通常用于单一效果或页面跳转。
- `css/`、`images/`：根目录页面使用的通用样式和素材。

### 练习模块（Exercises）
- `E2 Grid/`：Grid 排版练习。
- `E3 Fonts & Animation/`：字体与动画练习。
- `E4 Flexbox/`：Flex 布局练习。
- `E5 Responsiveness/`：响应式页面练习。
- `E6 JavaScript/IMW_Winter_2024_E6-JavaScript/`：JavaScript 基础语法和 DOM 操作练习。
- `E7 jQuery/14429-150/Exercise 6/`：jQuery 动态网格交互练习。
- `E8 JSON/Exercise 8/`：JSON 相关练习页面。
- `E9 Favicon/Exercise 9/`：favicon 与站点图标练习。

### 项目模块（Projects）
- `P1 Storybook/`：多页叙事型页面项目（从 `index.html` 到 `challenge.html` / `end.html`）。
- `P2 Poster/poster/`：海报视觉项目（主页 + 详情页 + 过程页），含对应 CSS 与图片资源。
- `P3 Interaction/14545/`：交互项目，含打字游戏逻辑和视觉布局。

> 备注：仓库中还存在一个根目录 `poster/`，与 `P2 Poster/poster/` 结构高度相似，可视作历史拷贝或部署副本；维护时建议优先确认主维护目录，避免“双写”。

## 2) 新人需要优先了解的关键内容

### A. 这是“作品集合仓库”，不是工程化应用
- 当前没有构建系统（如 Vite/Webpack）和包管理依赖（`package.json`）。
- 主要开发方式是“直接编辑 HTML/CSS/JS，然后浏览器打开页面验证”。
- 多页面之间是松耦合关系：每个练习或项目大多可独立运行。

### B. 三类核心能力在代码里如何体现
1. **布局能力（HTML + CSS）**
   - 在 `E2/E4/E5` 体现 Grid/Flex/响应式基础。
2. **视觉表达（动画与图形）**
   - 在 `E3` 和部分项目中大量使用渐变、定位、动画、分层结构。
3. **交互能力（JS/jQuery）**
   - `E6`：事件、循环、条件、定时器、表单输入。
   - `E7`：jQuery 批量创建元素、事件绑定、样式动态变更。
   - `P3` 与根目录 `index.js`：更完整的交互流程（计时、计分、字符重排等）。

### C. 新人第一次阅读建议看的文件
按顺序阅读能最快建立“全局 -> 局部”的理解：
1. `index.html`（看页面整体分区和各交互块容器）
2. `style.css`（看视觉系统如何分层组织）
3. `index.js`（看一次完整的小游戏状态流转）
4. `E6 JavaScript/.../index.js`（看基础语法练习范式）
5. `E7 jQuery/.../sketch.js`（看 jQuery 风格写法）
6. `P1/P2/P3` 各自入口页（看项目级结构组织）

## 3) 后续学习建议（新人 2~4 周路线）

### 第 1 周：先把页面“跑起来”
- 用 VS Code + Live Server（或任意静态服务器）分别打开：
  - 根目录 `index.html`
  - `P1 Storybook/index.html`
  - `P2 Poster/poster/index.html`
  - `P3 Interaction/14545/index.html`
- 目标：明确每个子目录是“独立作品单元”。

### 第 2 周：做 3 个小改动练手
- 改一个布局：在 `E4` 或 `E5` 调整区块排列并保持响应式。
- 改一个视觉：在 `P2` 调整配色/字体/动画速度。
- 改一个交互：在 `P3` 调整游戏时间、难度或得分规则。

### 第 3 周：补齐工程意识
- 增加基础文档：每个项目目录补一个简短 README（用途、入口、资源来源）。
- 做代码整理：统一命名风格、减少重复样式、抽离公共 CSS。
- 检查重复目录（如 `poster/` 与 `P2 Poster/poster/`）并确定唯一维护源。

### 第 4 周：向现代前端迁移（可选）
- 在不改 UI 的前提下，先做最小工程化：
  - 引入格式化工具（Prettier）
  - 引入静态检查（ESLint）
  - 用 Vite 建一个“作品索引页”统一导航到各练习/项目
- 目标不是重写，而是把现有作品“可维护化”。

---

## 4) 给新人的协作建议
- 新增功能优先放在对应练习/项目目录，避免把所有代码堆到根目录。
- 改动前先确认“该目录是否有历史副本”。
- 每次提交只做一类改动（样式/结构/交互分开），便于回滚。
- 给视觉参数加注释（颜色、尺寸、动画时长），后续同学更容易接手。

如果你是第一次参与这个仓库，建议从 `P3 Interaction/14545` 的 `index.js` 开始，它最能帮助你理解这个仓库里“交互逻辑 + 视觉反馈”的结合方式。
